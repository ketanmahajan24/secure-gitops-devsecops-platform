# 📌 Project Overview

This project implements a **Secure GitOps-Based DevSecOps Platform** that integrates security, automation, containerization, infrastructure provisioning, deployment, monitoring, and rollback mechanisms into a single unified CI/CD workflow.

It ensures:

* ✅ Shift-left security
* ✅ Automated CI/CD
* ✅ Infrastructure as Code (IaC)
* ✅ GitOps-based deployment
* ✅ Continuous monitoring & alerting
* ✅ Production-ready Kubernetes deployment

---

# 🏗️ Architecture Overview

## 🔁 Complete Workflow

1. Developer commits code to Git
2. Jenkins CI pipeline triggers automatically
3. SonarQube performs static code analysis
4. OWASP Dependency-Check scans libraries
5. Trivy scans Docker images
6. Docker builds and pushes image
7. Argo CD syncs Kubernetes manifests
8. Kubernetes deploys application
9. Prometheus collects metrics
10. Grafana visualizes dashboards
11. Alertmanager sends alerts
